# Deb Archive

Portfolio of Precious Deborah Grace Acerdano. Plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Pages
`index.html` · `about.html` · `projects.html` · `case-studies.html` · `testimonials.html` · `contact.html` · `review.html` (private, not in the menu; send this link to clients)

## Asset naming
All files live in `images/`, one folder per section. Names are lowercase, words joined with hyphens, no spaces.

Pattern: `section-subject-detail.ext`, with two-digit numbers for a series (`-01`, `-02`).

| Folder | Example |
|---|---|
| `images/brand/` | `debarchive-logo-orange.png` |
| `images/about/` | `toolkit-social-media.png` |
| `images/social/` (+ `thumbs/`) | `social-tulloch-hr-strategy.jpg` |
| `images/collateral/` | `collateral-rival-coffee-table-tent.jpg` |
| `images/branding/` | `branding-crabby-brand-board.jpg` |
| `images/email/` | `email-product-launch-01.jpg` |
| `images/ai/` | `ai-prompt-engineering-nitro-bar.jpg` |
| `images/app/` | `app-cleandrop-screens.jpg` |
| `images/case-studies/` (+ `thumbs/`) | `case-study-01-facebook-community.jpg` |

When adding an image, give it a descriptive `alt` that says what is in the picture.

## Adding an approved review
Open `testimonials.html`, copy one review card, and change the quote, name, initials and role. Every card shows the "Verified client" badge automatically.
